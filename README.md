# DeployEmploy - Starter Site

This repository is a minimal starter for the DeployEmploy website.

Features included:
- Vite + React + TypeScript
- Tailwind CSS (configured)
- react-three-fiber + drei for a 3D hero scene

Quick start

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

Notes

- This is a starter scaffold. Replace the placeholder 3D character in `src/components/Hero3D.tsx` with your GLTF/GLB models when available.
- Add additional pages and components in `src/pages` and `src/components`.
